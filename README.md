# مقطوب | Maqtoop

مستودع المشروع الجديد. المرحلة الحالية: تهيئة Git وتخطيط التنفيذ فقط.

لم يبدأ تطوير الخادم أو التطبيقات أو قاعدة البيانات.

## ابدأ من هنا

- [دليل المشروع الكامل](PROJECT_GUIDE.md): القرارات، المتطلبات، البنية المقترحة، المهارات، طريقة العمل والاختبار والتسليم.
- [تعليمات الوكلاء](AGENTS.md): قواعد مختصرة تنطبق على المستودع كله.

على أي مطور أو وكيل قراءة الدليل وفحص حالة الملفات قبل البدء. ما يرد في خارطة الطريق ليس تفويضًا بتنفيذه تلقائيًا.

## القنوات المعتمدة
- العميل: Android وiOS.
- التاجر: Android وiOS وWindows.
- الإدارة: Windows فقط.
- المندوب: Android.
- لا واجهات ويب ضمن المشروع.

## العمل المشترك
ابدأ كل تغيير بفرع قصير مرتبط بمهمة معتمدة، ثم Pull Request يوضح السبب ومعايير القبول والتحقق. يلزم مراجع غير المؤلف. لا ترفع الأسرار أو بيانات العملاء أو المستندات الداخلية إلى هذا المستودع العام.

الخطة التنفيذية PDF محفوظة محليًا للمراجعة؛ لا تعد هذه التهيئة تنفيذًا لخطة التطوير أو دليلًا على جاهزية النظام.
