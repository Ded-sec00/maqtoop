# مقطوب | Maqtoop

مستودع مقطوب. المرحلة الحالية تنفيذ وتجربة أول مسار شراء والحسابات وتسجيل الدخول عبر API وPostgreSQL.

أضيفت المرحلةA لمسودات الكتالوج والمراجعة الداخلية والصور الخاصة؛ [عقدها وحدودها](docs/design/CATALOG_API.md). النشر والبيع من هذه المسودات متوقفان بانتظار سعر البيع والضمان.

إدارة صلاحيات فروع التاجر عبر API موضحة في [عقد الفروع](docs/design/BRANCH_PERMISSIONS_API.md): منح وسحب إداريان مع نسخ وتدقيق ومنع تكرار، وفحص التفويض بعد انتظار الأقفال.

تدعم قائمة مسودات التاجر البحث بالماركة والموديل والتصفية بالحالة والفرع والصفحات، مع الاقتصار على مسودات صاحب الحساب وفروعه المخولة؛ [العقد](docs/design/CATALOG_API.md).

سجل النسخ والمقارنة يتيح المحتوى المحفوظ ومراجعاته وفروق الحقول والصور للإدارة وصاحب المسودة المخول فقط؛ [العقد](docs/design/CATALOG_HISTORY_API.md). لا يفتح النشر أو البيع.

قائمة مراجعة الإدارة تدعم البحث والتصفية بالتاجر والفرع والحالة والصفحات، معرفض الجلسة الملغاة بعدانتظار الأقفال؛ [العقد](docs/design/ADMIN_REVIEW_LIST_API.md). النشر والبيع من المسودات يظلان مقفلين.

يوجد نموذج PostgreSQL تجريبي واختبارات تشغيل في [db/first_purchase](db/first_purchase/README.md). تفاصيل الحالة والفحوص في [تقرير المراجعة](docs/verification/FIRST_PURCHASE_REVIEW.md).

تشغيل الاختبارات الآلي وشروط النجاح وحماية الدمج موضحة في [دليل CI](docs/operations/CI.md).

## القنوات المعتمدة
- العميل: Android وiOS.
- التاجر: Android وiOS وWindows.
- الإدارة: Windows فقط.
- المندوب: Android.
- لا واجهات ويب ضمن المشروع.

## العمل المشترك
ابدأ كل تغيير بفرع قصير مرتبط بمهمة معتمدة، ثم Pull Request يوضح السبب ومعايير القبول والتحقق. يلزم مراجع غير المؤلف. لا ترفع الأسرار أو بيانات العملاء أو المستندات الداخلية إلى هذا المستودع العام.

الخطة التنفيذية PDF محفوظة محليًا للمراجعة؛ لا تعد هذه التهيئة تنفيذًا لخطة التطوير أو دليلًا على جاهزية النظام.
