# مقطوب | Maqtoop

مستودع مقطوب. المرحلة الحالية تنفيذ وتجربة أول مسار شراء والحسابات وتسجيل الدخول عبر API وPostgreSQL.

يوجد نموذج PostgreSQL تجريبي واختبارات تشغيل في [db/first_purchase](db/first_purchase/README.md). تفاصيل الحالة والفحوص في [تقرير المراجعة](docs/verification/FIRST_PURCHASE_REVIEW.md).

تشغيل الاختبارات الآلي وشروط النجاح وحماية الدمج موضحة في [دليل CI](docs/operations/CI.md).

## ابدأ من هنا

- [دليل المشروع الكامل](PROJECT_GUIDE.md): القرارات، المتطلبات، البنية المقترحة، المهارات، طريقة العمل والاختبار والتسليم.
- [تعليمات الوكلاء](AGENTS.md): قواعد مختصرة تنطبق على المستودع كله.
- [قواعد عمل الوكلاء](RULES.md): 20 قاعدة قبل التنفيذ وأثناءه وعند التحقق والتسليم؛ نقاط الدخول في AGENTS وGEMINI وCLAUDE وCursor تحيل إلى المرجع نفسه.
- [خطة النسخ الاحتياطي والاستعادة](docs/operations/BACKUP_AND_RECOVERY.md): الأهداف والجدول والاحتفاظ والمفاتيح والمسؤوليات والتمارين ومهام التنفيذ. خطة موثقة، وليست نسخًا مفعلة.
- [خطة التنفيذ كاملة بصيغة Markdown](EXECUTION_PLAN.md): جميع محتويات خطة PDF ذات 31 صفحة.
- [برومبتات Antigravity والتسليم للمراجعة](docs/agents/ANTIGRAVITY_PROMPTS.md): قوالب دخول الوكيل وتجهيز البيئة وتسليم النتائج، تستخدم بحسب تكليف المالك.
- [المهارات المحلية](.agents/skills/): سلامة الأموال والمخزون، عقود API، والتحقق من النسخ والاستعادة.
- [حزمة قرارات التنفيذ](docs/decisions/IMPLEMENTATION_DECISIONS.md) و[تقرير الجاهزية](docs/verification/ANTIGRAVITY_READINESS.md) و[خطة تجهيز البيئة](docs/verification/ENVIRONMENT_SETUP_PLAN.md): قرارات وتقارير مؤرخة للمراجعة، وليست إعلانًا عن اكتمال التشغيل.

على أي مطور أو وكيل قراءة الدليل وفحص حالة الملفات قبل البدء. ما يرد في خارطة الطريق ليس تفويضًا بتنفيذه تلقائيًا.

## القنوات المعتمدة
- العميل: Android وiOS.
- التاجر: Android وiOS وWindows.
- الإدارة: Windows فقط.
- المندوب: Android.
- لا واجهات ويب ضمن المشروع.

## العمل المشترك
ابدأ كل تغيير بفرع قصير مرتبط بمهمة معتمدة، ثم Pull Request يوضح السبب ومعايير القبول والتحقق. يلزم مراجع غير المؤلف. لا ترفع الأسرار أو بيانات العملاء أو المستندات الداخلية إلى هذا المستودع العام.

الخطة التنفيذية PDF محفوظة محليًا للمراجعة؛ لا تعد هذه التهيئة تنفيذًا لخطة التطوير أو دليلًا على جاهزية النظام.
