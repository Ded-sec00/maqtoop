## حالات الدفع الواجب اختبارها قبل قبول التنفيذ

| الحالة | النتيجة المطلوبة أو القرار المعلّق |
|---|---|
| عميلان يؤكدان آخر قطعة في وقت واحد | يفوز حجز واحد ويُبلّغ الآخر بعدم التوفر. لا يولد مجرد فتح السلة حجزًا. |
| انقطع الاتصال بعد إرسال الدفع وقبل معرفة نتيجته | مقترح تصميم: تُحفظ المحاولة معلقة وتُطابق مع المزود قبل أي تحصيل جديد. سرعة الدفع المعتادة لا تحسم نتيجة محاولة انقطع ردها. |
| تأكيد النجاح يصل بالتزامن مع تحرير الحجز | يحسم الخادم ملكية القطعة مرة واحدة. إذا كانت متاحة والسعر ساريًا يكتمل الطلب، وإذا بيعت تطبق حالة 2113. |
| تأكيد مكرر أو متأخر بعد إتمام الطلب | يُربط بالمحاولة الأصلية؛ لا قيد أو خصم أو حجز أو شحن إضافي. يلزم اختبار إشعارين متزامنين أيضًا. |
| فشل مؤكد ثم إشعار متعارض، أو نجاح بعد انقضاء ساعة السعر | تُراجع نتيجة المزود والمحاولة. يلزم اعتماد معالجة الدفعة المحصلة فعلًا إذا تغيّر السعر؛ لا يُطلب تحصيل جديد تلقائيًا. |
| انقطاع بعد شحن المحفظة وقبل دفع الطلب | تُفصل عملية الشحن عن الطلب. تكرار تأكيد الشحن لا يضاعف الرصيد، والعودة للسلة تعيد فحص السعر والكمية. |
