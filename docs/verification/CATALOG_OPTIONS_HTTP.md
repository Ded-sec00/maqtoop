## دورة التحقق

أضيفت حالة catalog-options-http أول المجموعة قبل التنفيذ. فشلت404 بدل200 عند GET /v1/merchant/catalog/branches، وخرج الحارس1 مع0/87؛ هذه نتيجة حمراء متوقعة وليست نجاحًا. بعد إضافة المسارات والدالة نجحت الحالة الأساسية والمجموعة87/87. ثم توسع اختبار الخيارات بالتغطية التالية وتُثبت نتيجة التشغيل النهائي أدناه عند اكتماله.
