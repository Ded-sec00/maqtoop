# تنفيذ فروع التاجر ومصادر مرشحات الإدارة

> **For agentic workers:** استخدم superpowers:executing-plans لتنفيذ الخطوات والاختبارات، ومراجعة مستقلة واحدة في النهاية.

**Goal:** توفير مصادر خيارات حقيقية للواجهات الأصلية دون الاعتماد على مسودات محملة أو معرفات حسابات مختلفة عن معرفات التجار.

**Architecture:** ثلاثة GET خلف catalog.enabled: /v1/merchant/catalog/branches، /v1/admin/catalog/merchants، /v1/admin/catalog/merchants/{merchantId}/branches. محلل موحد محدود ودالة SQL للقراءة بصلاحية DEFINER تتحقق من الدور وتعيد الجلسة والتفويض بعد الأقفال. لا تعديل جداول الأعمال.

**Tech Stack:** Node.js وpg وPostgreSQL16.16 والاختبارات القائمة. لا اعتماديات جديدة.

**Spec:** طلب المستخدم تنفيذ G1 ومصادر خيارات G2، وR03 وdocs/design/CATALOG_API.md وBRANCH_PERMISSIONS_API.md وADMIN_REVIEW_LIST_API.md. الوثيقة الخاصة تبقى خارج Git؛ هذه الخطة لا تنسخ المرفقات.

## Global Constraints

- API للتاجر Android/iOS/Windows والإدارة Windows فقط؛ لا واجهات ويب أو تغييرات سياسات سعر أو ضمان أو7291.
- فرع التاجر من تفويضه النشط ومنشأته معًا؛ لا هوية من العميل. لا منح أو إنشاء فروع عبر الخيارات.
- المعرفات bigint موجبة كنص، cursor رقمي keyset، q حرفي حتى100، limit1–100 افتراضي50؛ أسماء التجار من القاعدة.
- جدول الفرع لا يحتوي اسمًا: displayName مشتق «الفرع {branchId}» واسم فعلي غير مفترض. لا تغيير schema لتسمية الفروع في هذه المهمة.
- قائمة فروع الإدارة تحت تاجر محدد؛ غيّر التاجر أو البحث وابدأ بلا cursor. لا إثراء تفاصيل المسودة أو فهرس حسابات جديد.
- approve يبقى409 وقائمة العميل فارغة؛ لا مخزون أو مال أو نشر جديد.

## Review Focus

1. تفويض خاطئ لفرع منشأة أخرى لا يسربه؛ اختبارات SQL fixture وHTTP للأدوار كلها.
2. سحب الفرع مثبت أثناء انتظار قفل بيانات الفرع: لا تظهر صلاحية قديمة؛ grant جديد أثناء القراءة يظهر بالطلب التالي.
3. logout-all وتغيير الكلمة والإيقاف/إعادة التفعيل أثناء أقفال حقيقية:401 دون items؛ دخول جديد ينجح.
4. أكثر من100 خيار وبيانات بلا مسودات، وبحث عربي ورموز حرفية ومعرفات كبيرة: صفحات بلا فقد أو تكرار أو فقد دقة.
5. GET لا يكتب، وترحيلة فاشلة قبل COMMIT تحفظ السابق، ولا PUBLIC EXECUTE أو grants جداول. لا ادعاء نسخ/PITR.
